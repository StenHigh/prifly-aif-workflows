# aif-classic-continuation

Continuation quality tail generated from `aif-classic`: `resume → verify → security → review → commit` over the tree a partial, rejected or cancelled classic Run left. Start it with `prifly project continue`; its first step is a Node program, so allow `node` in `.prifly/local.yaml` and pass `--allow-execution`. Needs Pri-Fly 0.13.58. See "Продолжение" in the repository README.
