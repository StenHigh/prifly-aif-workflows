# Самостоятельный аудит тестов

Пользователь предложил адаптировать OpenClaw `test-audit` и уточнил границу:
отдельный workflow; в classic и другие существующие маршруты его не вставлять.
Разработчики подключают компоненты сами через проектный `extend.yaml`.

По уточнению владельца имя использует vendor исходного skill:
`openclaw-test-audit`, namespace компонентов `openclaw:`. AI Factory skills
пакету не нужны. Версия начальная `1.0.0`, пакет ещё не публиковался.

Новый пакет `openclaw-test-audit@1.0.0` проверяет изменённые тестовые пути текущей
задачи. Пустая выборка обходится без AI-сессии. Непустая получает read-only
review и машинную проверку полного списка путей и свежести candidate.
Тесты текущей задачи определяются относительно исходного base commit и явно
заданных проектом patterns. Учитываются добавления внутри существующих файлов,
изменения, удаления, index и nonignored untracked файлы.

В пакет не входят production edits, массовое удаление тестов, test execution,
repair, commit, публикация или скрытый запуск других Runs. Semantics checklist
перенесены во встроенный context с закреплённым upstream commit и MIT license;
OpenClaw tooling/runtime не нужен. Отчёт reader — наблюдения/суждения хоста,
не машинное доказательство полезности тестов.

Released Pri-Fly остаётся `0.13.77`; новых stable при начале задачи нет.
Семь существующих package trees должны остаться неизменными. Публикация нового
пакета и bump общего release не выполняются в рамках локальной подготовки.
