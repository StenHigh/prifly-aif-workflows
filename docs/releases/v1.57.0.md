# v1.57.0 — unified composition and original report references

Status: release candidate. Publication and catalog updates follow final CI and public installation checks.

Classic, profiled, fix and UI/UX become **2.0.0**. They expose scoped `/5` points
and public components with an explicit shared schema dependency. Feature becomes
**1.4.0** for optional report references; its embedded review contract stays unchanged.
Fanout, review-evidence and test-audit retain their published versions and bytes.

Core **0.13.86** is required for the complete composition + named worktree path.
Its [published acceptance](../changes/adopt-unified-composition-v5/core-0.13.86.md)
includes signatures, managed update and an actual named Run. Published Core `/4`
and saved Runs keep their existing contracts.

```text
project measurement → original report refs → verify/review → repair → new measurement
```

`implementation.reports` carries ordinary ArtifactRefs. Readers preserve original
subject, basis, exits and failed/unavailable/unknown evidence. They judge applicability;
refs alone never establish success. Sufficient evidence can avoid a repeated measurement.
Missing required evidence needs the missing measurement or an honest blocked result.
Read-only readers do not provision runtime; a project-owned Step declares those effects.

## Installation and migration

Use the [complete release guide](../changes/adopt-unified-composition-v5/release-guide.md)
for exact source checkout, native add/update and explicit contract installation.
The shared package1.2.0 pins frozen1.0.0: 17 exact schemas in total.
A catalog install copies only one workflow folder. It does not install `contracts/`
or repository tools. Run the checked installer from the exact release checkout.

Migrate owner extensions deliberately to `/5`. Preserve task inputs and the
point's declared consumers. Native update preserves owner files but does not
translate them or rewrite old Runs. Finish or inspect old Runs before upgrading.

[Runnable public-import example](../../examples/unified-composition/README.md)
shows complete prepare/start and supported continue commands. The low-level
configure/quality wrapper supports its declared continuation. The minimal
task-aware wrapper has one root Call and does not declare resume.
