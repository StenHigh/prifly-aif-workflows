# v1.54.0 — читаемые classic и profiled

Состав первой порции issue #6: `aif-classic@1.48.0`, `aif-profiled@1.49.0`.

`aif-classic` раскрывает сложные YAML mappings корня и verify-loop.
Verify bridge находится в Markdown через существующий `context.source`.
README показывает маршрут и файлы. `aif-profiled` получает изменение штатным derive.
Instructions, ID, схемы, условия, limits и маршруты сохраняют прежнее поведение.
Ускорение чтения не измерялось; владелец принял форму по review.

```text
блочный YAML + Markdown + README → classic → штатный derive → profiled
                                            ↓
                               версии → ворота → tag → catalog → update
```

## Установка и обновление

```sh
prifly project workflows add StenHigh/prifly-aif-workflows   --path aif-classic --ref v1.54.0 --repository .
prifly project workflows add StenHigh/prifly-aif-workflows   --path aif-profiled --ref v1.54.0 --repository .
# Для уже установленных пакетов:
prifly project workflows update aif-classic --ref v1.54.0 --repository .
prifly project workflows update aif-profiled --ref v1.54.0 --repository .
```

Выбирайте add либо update для нужного пакета. Update сохраняет `extend.yaml` и `project/`.
Local upstream edits вызывают отказ и требуют отдельного разбора.
Незавершённые Runs рекомендуется завершить до обновления author versions.
При `recover_prefix_changed` выбирайте явный reviewed replay; автоматический resume не обещается.

Готовые task и команды prepare/start/continue: [classic example](../../examples/classic/README.md).
Opt-in review/UI/UX остаётся [проектным W6 recipe](../../examples/review-uiux-extensions/README.md).
Минимальный Pri-Fly остаётся0.13.64; выпуск проверяется на official0.13.82.
Остальные шесть пакетов сохраняют bytes и версии v1.53.0 в этой порции.
