# v1.58.0 — проектный предел task.description

Статус: планируемый выпуск; tag и Release не опубликованы.
Classic/profiled/fix становятся 3.0.0 и требуют Pri-Fly0.13.90+.
Проект задаёт `task_description_limit` в `project/compile-values.yaml` установленного workflow.
Default остаётся 12 000 Unicode-символов; пример32 000 принимает полный task длиной16 557.

Task1.2.0 принадлежит source owner и получает exact compiled ref после применения параметра.
Project consumers переходят с `{{contract_schema_task}}` на `{{schema_task}}`.
Старый shared task1.1.0 и manifest общих contracts сохраняют прежние bytes.
Update сохраняет owner file. Изменение значения требует нового launch review.
Существующий Run сохраняет definitions/task; несовместимый continue отказывает до нового Run и эффектов.

```text
owner config -> единый task contract -> root/plan/nested readers/repair
                                          |
                                    immutable Run
```
