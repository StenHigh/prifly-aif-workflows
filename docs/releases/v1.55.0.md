## Установка

Устанавливайте только нужные пакеты. Ниже NAME заменяется именем из таблицы:

```sh
prifly project workflows add StenHigh/prifly-aif-workflows --path NAME --ref v1.55.0 --repository .
```

Также доступна установка нужного имени через обновлённый каталог: `prifly project workflows add NAME --repository .`.
Для уже установленного пакета:

```sh
prifly project workflows update NAME --ref v1.55.0 --repository .
```

Update сохраняет extend.yaml и project/. Local upstream edits вызывают отказ.
Новые author versions меняют identity. Завершите старые Runs перед обновлением.
Сначала выполните continue --prepare; recover_prefix_changed требует явного reviewed replay.
После отмены writer/environment effect сначала нужен осмотр и требуемое resolution/reconcile.
Fanout не объявляет resumable; его continue не поддерживается.
