Use pinned aif-commit for local commits only; never push. Read the actual
claimed tree and the previous implementation/result. This workflow never
owns ordinary PLAN.md or any discovered unrelated FIX_PLAN: leave them intact.
Default fix-plan was already captured and removed by Pri-Fly; do not delete
anything if optional fix_plan is absent. If present, the manifest and pinned
fix-path identify this Run's plan; verify its sealed bytes against the actual
file before staging the retained custom plan's final progress. An intervening
edit not covered by quality evidence is owner_required, not implicit approval.
Preserve the custom tracked plan, learning patches and
project overlays. Commit only this task's remaining changes; do not sweep
unrelated staged work into its commit. If nothing remains, skip the skill.
Preserve base_commit from input, recompute head_commit and changed_files from
the real tree. Return implementation and result for every verdict. A commit
problem is owner_required or environment_unavailable with its reason; success
keeps the last fixed regression evidence. No native push/grouping dialog or
claim that a declared answer grants an external effect.

## Original report references

`implementation.reports`, when present, contains ordinary ArtifactRefs.
Preserve every original ref, its basis and its failed/unavailable/unknown state.
Read each declared ref through Pri-Fly artifact export; use declared report/log
refs only. Never scan arbitrary JSON or depend on an earlier Attempt directory.
A digest or schema does not establish success or applicability. Compare the
actual candidate, behavior, settings, selection, methods and environment with
what the original report measured. A changed SHA alone is not an instruction
to repeat all checks. Reuse sufficient applicable evidence without rerunning
its measurement. Missing, stale, corrupt or unavailable required evidence
requires the missing measurement or an honest blocked assessment. Do not run
an implicit full suite. A read-only reader cannot provision an external runtime;
a project-owned /5 measurement with declared effects runs before this reader.
Writers preserve inherited reports and append declared new report refs when
available. Never relabel old counts, subject, basis, exits or status for new work.
